# Abartılı Kedi Felsefe Jeneratörü

Bu repository, insanlık tarihinin en önemli projelerinden biridir. Kedilerin derin felsefi düşüncelerini simüle ederek evrenin anlamını çözmeyi amaçlar. Her çalıştırılışta yeni bir kedi bilgeliği ortaya çıkar ve kullanıcıyı varoluşsal bir krize sürükler.

## Nasıl Çalışır?

```bash
python kedi_felsefe.py
```

Bu komut, rastgele bir kedi felsefesi cümlesi üretir. Dikkat: Aşırı kullanım önerilmez, çünkü kediler gerçekten de her şeyi bilir.

## Özellikler

- Tamamen çalışan kod
- Abartılı ciddiyet
- Saçma sapan ama komik çıktılar
- Kedilerle ilgili her şey (patates yok, söz)

## Katkıda Bulunma

Lütfen kedilere saygılı olun. Pull request'ler kabul edilir, ama sadece eğer kedi onar ederse.
